Configuração necessária

Esta app ainda não está ligada a nenhuma base de dados. Abre o ficheiro rondas-standalone.html num editor de texto, encontra o bloco FIREBASE_CONFIG perto do fim do ficheiro, e substitui os valores pelos do teu projeto Firebase (ver guia de configuração fornecido).

Depois de guardares o ficheiro com os valores corretos, atualiza esta página.
